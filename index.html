DISCRETE MATHEMATICS

Set Logic ของเว็บไซต์

การประยุกต์ใช้ Set Theory และ Logic กับระบบสินค้า BODYMASK PATTY

A ∪ B

Union

ใช้ในการรวมสินค้าของ SET A และ SET B

SET A ∪ SET B = สินค้าทั้งหมดที่อยู่ใน SET A หรือ SET B

A − B

Difference

ใช้หาสินค้าที่อยู่ใน SET A แต่ไม่อยู่ใน SET B

ตัวอย่างเช่น สินค้า Exclusive ของ SET A

A ∩ B

Intersection

ใช้หาสินค้าที่มีอยู่ร่วมกัน ใน SET A และ SET B

เช่น Body Mask และ Body Scrub ที่อยู่ในทั้งสองเซ็ต

IF / ELSE

เงื่อนไข

ใช้ตรวจสอบเงื่อนไข การลดราคาและการแนะนำสินค้า

ถ้าซื้อ SET → ได้ราคาพิเศษ
